Documentação da API - RavenaBot

Guia de referência para integração direta com os serviços de Inteligência Artificial, Síntese de Voz, Transcrição e Assistente do RavenaBot.

Autenticação e Rate Limits

As requisições que partem do próprio domínio web do bot possuem acesso liberado pelo navegador. Requisições de APIs externas, scripts ou clientes remotos devem incluir a chave de API em um dos seguintes cabeçalhos HTTP:

Header: X-API-Key: rav_live_sua_chave_aqui Header: Authorization: Bearer rav_live_sua_chave_aqui

O rate limit é reiniciado a cada 60 segundos. Os cabeçalhos de resposta X-RateLimit-Limit, X-RateLimit-Remaining e X-RateLimit-Reset informam o consumo restante.

POST /api/imagine/generate 5 req / min

Gera uma imagem de alta qualidade através do pipeline Bonsai SDXL.

Request Body (JSON)
{ "prompt": "um corvo gótico sobrevoando uma floresta mágica e sombria" }
Exemplo cURL
curl -X POST https://ravena.moothz.win/api/imagine/generate \ -H "Content-Type: application/json" \ -H "X-API-Key: SUA_CHAVE_API" \ -d '{"prompt": "gato cibernético neon"}' \ --output imagem.jpg
Resposta

Buffer binário da imagem JPEG (image/jpeg) em resolução 1024x1024.

POST /api/tts/generate 20 req / min

Sintetiza texto em fala humana natural (F5-TTS).

Request Body (JSON)
{ "text": "Olá! Esta é uma demonstração de síntese de voz da Ravena.", "voice": "ravena" // Opcional: "ravena", "rubao", "mulher", "homem", "carioca", "narrador" }
Exemplo cURL
curl -X POST https://ravena.moothz.win/api/tts/generate \ -H "Content-Type: application/json" \ -H "X-API-Key: SUA_CHAVE_API" \ -d '{"text": "Bom dia a todos!", "voice": "ravena"}' \ --output audio.mp3
Resposta

Áudio MP3 (audio/mpeg).

POST /api/stt/transcrever 10 req / min

Envia arquivo de áudio ou vídeo para transcrição assíncrona (Whisper).

Request (multipart/form-data)
Campo: "audio" (Arquivo de áudio/vídeo, máx 50MB)
Exemplo cURL
curl -X POST https://ravena.moothz.win/api/stt/transcrever \ -H "X-API-Key: SUA_CHAVE_API" \ -F "audio=@gravacao.ogg"
Resposta
{ "jobId": "c56a4180-65aa-42ec-a945-5fd21dec0538" }
GET /api/stt/status/:jobId Consultas de Status

Consulta o status de processamento e o resultado de uma transcrição STT.

Exemplo cURL
curl https://ravena.moothz.win/api/stt/status/c56a4180-65aa-42ec-a945-5fd21dec0538
Resposta
{ "id": "c56a4180-65aa-42ec-a945-5fd21dec0538", "status": "complete", // "starting" | "transcribing" | "complete" | "error" "result": "Texto transcrito com precisão da gravação de áudio.", "estimatedTime": 2 }
POST /api/ajuda/chat 10 req / min

Envia perguntas e instruções para o LLM com contexto da Ravena e ferramentas integradas.

Request Body (JSON)
{ "message": "Como funciona o sistema de pescaria?", "sessionId": "opcional_id_de_sessao" }
Exemplo cURL
curl -X POST https://ravena.moothz.win/api/ajuda/chat \ -H "Content-Type: application/json" \ -H "X-API-Key: SUA_CHAVE_API" \ -d '{"message": "Quais são os comandos de administração?"}'
Resposta
{ "answer": "Os comandos de administração iniciam com `!g-` como `!g-painel`, `!g-addCmd`..." }
GET /api/services/status Monitoramento

Retorna o status em tempo real dos serviços (whisper, imagine, f5tts, llm).

Resposta
{ "whisper": "up", "imagine": "up", "f5tts": "up", "llm": "up" }
